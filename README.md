# Azen
<img width="1920" height="1080" alt="screenshot" src="https://github.com/user-attachments/assets/f44c0054-5be2-451f-9c80-3f1fa2d17667" />
Azen(OS) is an operating system based on AnduinOS. Unlike traditional OS distributions—and due to limitations in time and technical resources—we release configuration files that allow users to customize the AnduinOS interface and optimize their experience.
We have developed a technology called ALRM (Azen Laptop Resources Management) designed to enhance the overall performance of low-end laptops. It improves features such as deep sleep upon lid closure and reduces resource consumption by background processes. We are continuously refining this technology; thank you for your support!
